# OLX India Classifieds Scraper Promotion Notes

## Positioning

Collect structured public OLX India classifieds listings for resale price research, local marketplace monitoring, and category-level demand analysis.

## Best small demo

- Keyword: `iphone`
- Location: `Mumbai`
- Maximum results: `1`
- Item details: off
- Description: off
- Proxy: off

Show the input, one clean listing row, and JSON or CSV export. Mention that richer item details and redacted descriptions are optional settings.

## LinkedIn draft

I published an OLX India Classifieds Scraper on Apify for structured public marketplace research.

It collects fields such as listing title, price, category, seller type, business seller flag, location, image URL, posting date, listing URL, and non-sensitive item parameters.

The safest first run is intentionally tiny: iphone, Mumbai, one result, details off, descriptions off, and proxy off. Check the output, then expand to more keywords, cities, price filters, or optional item details.

Useful for resale price tracking, local category research, recommerce analysis, and second-hand marketplace monitoring.

## Reddit or Discord draft

I built an Apify Actor that turns public OLX India listings into structured JSON/CSV data. It supports keywords, Indian locations, optional category IDs, price filters, result limits, optional item details, and redacted descriptions.

For a low-cost check, run iphone + Mumbai + one result with proxy off. Feedback on the schema and useful classifieds fields is welcome.
